# 🔐 Chaos Image Encryptor (Gauss Map)

Простой инструмент на C++ для шифрования и расшифрования PNG-изображений с использованием хаотического отображения Гаусса (Gauss Map). Программа выполняет потоковое XOR-шифрование каждого пикселя на основе последовательности, генерируемой из пароля.

---

## ✨ Возможности

- 🔑 **Ключ из пароля** — начальное значение `x0` вычисляется из произвольной строки-пароля
- 🌪️ **Хаотическая последовательность** — генерация псевдослучайных чисел через Gauss Map
- 🖼️ **Поточное шифрование** — XOR каждого канала (B, G, R) отдельным байтом хаоса
- 🔁 **Обратимость** — тот же пароль и тот же режим восстанавливают изображение
- 👁️ **Предпросмотр** — окна OpenCV для сравнения оригинала и результата

---

## 🧮 Математическая основа

**Отображение Гаусса:**

$$x_{n+1} = e^{-\alpha \cdot x_n^2} + \beta$$

где по умолчанию `α = 6.2`, `β = -0.5`. При таких параметрах система демонстрирует хаотическое поведение.

**Получение ключа из пароля:**

```cpp
key = 0.123456789;
for (char c : pass)
    key = fmod(fabs(key * 43.0 + (unsigned char)c * 0.111), 1.0);
x0 = key - 0.5;  // приводим к [-0.5, 0.5]
```

**Шифрование пикселя:**

```
x = gaussMap(x)
chaosByte = (unsigned char)(fmod(fabs(x) * 1000000.0, 256.0))
pixel[c] ^= chaosByte
```

## 📖 Использование

Запустите программу и следуйте подсказкам в консоли:

```
=== Шифрование изображения(.png) ===
Режим (e - шифрование, d - расшифрование): e
Введите пароль: my_secret_password
Путь к изображению: input.png
```

Результат будет сохранён рядом с исполняемым файлом:

| Режим | Выходной файл |
|-------|---------------|
| `e`   | `encrypted.png` |
| `d`   | `decrypted.png` |

> ⚠️ **Важно:** для корректного расшифрования используйте **тот же пароль**, что и при шифровании, и режим `d`. Просто применить XOR повторно в режиме `e` — недостаточно, т.к. программа ожидает переключение логики через режим.

## 🔍 Как это работает

1. **Инициализация ключа.** Пароль преобразуется в вещественное число `x0 ∈ [-0.5, 0.5]`.
2. **Разогрев.** Выполняется 1000 итераций `gaussMap`, чтобы отойти от начального значения и выйти на «хаотическую траекторию».
3. **Потоковое шифрование.** Для каждого пикселя и каждого канала (B, G, R):
   - генерируется следующее `x`;
   - из него берётся байт `chaosByte`;
   - выполняется `pixel[c] ^= chaosByte`.
4. **Сохранение.** Результат записывается в `encrypted.png` или `decrypted.png`.

Поскольку XOR — операция инволютивная, повторное применение той же последовательности восстанавливает исходные данные.

## ⚠️ Ограничения и предупреждения

- 🧪 **Учебный проект.** Это демонстрация хаотического шифрования, **не** криптостойкая система. Не используйте для защиты реально секретных данных.
- 🎨 **Сохранение в PNG.** Формат PNG сжат без потерь, поэтому шифрование/дешифрование проходит без искажений. **Не сохраняйте результат в JPEG** — потери сжатия сломают обратимость.
- 📏 **Только цветные изображения.** Используется `IMREAD_COLOR`; градации серого будут автоматически приведены к 3 каналам.
- 🔐 **Фиксированный пароль.** Смена пароля на один символ полностью меняет всю последовательность — надёжность зависит от энтропии пароля.
